# Экспериментальная модель v8

В этой папке сохранены параметры обучения и результаты проверки модели `v8` на пяти постоянных тестовых текстах. Модель пока не заменяет стабильную версию: автоматические метрики улучшились, но в сложных художественных текстах остаются смысловые и грамматические ошибки.

## Обучение

Модель обучалась с нуля от локальной базовой модели `models/rut5-base-absum` на 175 обучающих примерах. Ещё 75 примеров использовались для проверки во время обучения.

```powershell
python train_model.py --train-file data/train.json --validation-file data/validation.json --text-column text --summary-column summary --model-name models/rut5-base-absum --output-dir checkpoints/rut5-absum-finetuned-v8 --epochs 4 --learning-rate 5e-5 --label-smoothing-factor 0 --early-stopping-patience 2
```

Итоговое значение `eval_loss`: `2.348`. Оно не сравнивается напрямую с результатами предыдущих версий, потому что для `v8` отключено сглаживание меток.

## Результаты тестирования

- Среднее сокращение текста: `70.96%`.
- Средний `reference_token_f1`: `0.1437`.
- Средняя доля копирования исходного текста: `0.3265`.
- Количество тестовых текстов: `5`.

Полные ответы модели и метрики по каждому жанру находятся в `test_results.json`.

## Вывод

Модель лучше удерживает требуемую степень сокращения и меньше копирует исходный текст. При этом она иногда добавляет отсутствующие факты, нарушает смысл, повторяет слова и строит неграмотные предложения. Особенно заметны проблемы в деловых и классических художественных текстах, поэтому `v8` сохранена как экспериментальная версия.

Файл весов `model.safetensors` не хранится в Git: его размер около 932 МБ превышает лимит обычного репозитория GitHub. Модель можно воспроизвести указанной командой обучения.
