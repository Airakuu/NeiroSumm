# Экспериментальная модель v10

Версия `v10` обучена на датасете из 400 пар: 280 примеров использовались для
обучения и 120 для validation. Исходной точкой была локальная базовая модель
`models/rut5-base-absum`.

## Команда обучения

```powershell
python train_model.py --train-file data/train.json --validation-file data/validation.json --text-column text --summary-column summary --model-name models/rut5-base-absum --output-dir checkpoints/rut5-absum-finetuned-v10 --epochs 4 --learning-rate 5e-5 --label-smoothing-factor 0 --early-stopping-patience 2
```

Обучение на CPU заняло 19 минут 37 секунд. Итоговый validation-loss: `2.486`.

## Итоговые метрики

- Среднее сокращение: `73.18%`.
- Средний `reference_token_f1`: `0.1732`.
- Средняя доля копирования исходника: `0.3041`.
- Постоянных тестовых текстов: `5`.

## Ручная оценка

Учебный текст пересказан связно и без смысловых искажений. Информационный ответ
исказил изменение очереди, деловой ответ сформулирован неточно, а художественные
пересказы содержат ошибки согласования и лишние утверждения. Классическая проза
по-прежнему остаётся самым сложным жанром.

По сравнению с `v9` средний `reference_token_f1` вырос с `0.1361` до `0.1732`,
при этом целевой уровень сокращения около 70% сохранён. Однако одной удачной
метрики недостаточно для назначения версии основной: сначала нужно уменьшить
число смысловых и грамматических ошибок на постоянных тестах.

Полные результаты находятся в `test_results.json`. Файл весов не включён в Git,
потому что `model.safetensors` занимает около 932 МБ и превышает лимит обычного
репозитория GitHub.
