# Dataset Notes

В папке лежит набор примеров для дообучения модели суммаризации.

- `train.json` — обучающие примеры
- `validation.json` — проверочные примеры

## Формат записи

```json
{
  "text": "Полный исходный текст",
  "summary": "Краткое содержание"
}
```

## На что теперь ориентироваться

При добавлении новых примеров лучше соблюдать такие правила:

1. Исходные тексты должны быть достаточно длинными, чтобы модель училась сжимать объёмный материал, а не только короткие заметки.
2. Краткое содержание должно быть именно пересказом, а не набором почти дословно взятых предложений.
3. В summary лучше сохранять главную мысль, причинно-следственные связи и общий вывод текста.
4. Желательно держать единый стиль формулировок во всём датасете.
5. Если тема примеров меняется слишком резко, качество на маленьком датасете может падать.

## Что делать дальше

1. Добавлять больше длинных текстов в том же формате.
2. Следить, чтобы summary были переформулированы своими словами.
3. Постепенно довести набор хотя бы до 50-100 пар.
4. После каждого нового пакета примеров снова проверять качество модели на своих текстах.
