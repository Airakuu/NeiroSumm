# Summar

`Summar` — учебный проект на Python для автоматического создания краткого
пересказа русскоязычного текста. Модель не просто выбирает предложения из
исходника, а генерирует новое краткое содержание своими словами.

Проект умеет:

- суммаризировать текст из файла через консоль;
- показывать длину исходного текста, длину пересказа и процент сокращения;
- дообучать русскоязычную модель на собственном датасете;
- автоматически проверять новый чекпоинт на пяти постоянных текстах;
- предоставлять модель через HTTP API на FastAPI.

Основная рабочая модель — `checkpoints/rut5-absum-finetuned`, дообученная
версия `cointegrated/rut5-base-absum`. Она предназначена прежде всего для
информационных, учебных, деловых и современных художественных текстов.
Классическая проза пока остаётся отдельным сложным направлением.

## Главные команды

Все команды выполняются из корня проекта в PowerShell.

### 1. Установка

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -e .
```

### 2. Суммаризация текста

Поместите исходный текст в `text.txt` и выполните:

```powershell
python main.py --input-file text.txt
```

По умолчанию используется `checkpoints/rut5-absum-finetuned`. Другой
чекпоинт можно указать явно:

```powershell
python main.py --model-name checkpoints/rut5-absum-finetuned-v3 --input-file text.txt
```

В результате программа выведет краткое содержание, количество символов в
исходнике и пересказе, а также процент сокращения.

### 3. Загрузка базовой модели

```powershell
python download_model.py
```

Скрипт сохраняет модель в `models/rut5-base-absum` и умеет продолжать
прерванную загрузку.

### 4. Дообучение

Команда в одну строку для копирования:

```powershell
python train_model.py --train-file data/train.json --validation-file data/validation.json --text-column text --summary-column summary --model-name checkpoints/rut5-absum-finetuned --output-dir checkpoints/rut5-absum-finetuned-v4 --epochs 4 --learning-rate 5e-5
```

Новая версия будет записана в `checkpoints/rut5-absum-finetuned-v4`, поэтому
текущая рабочая модель не перезапишется. После обучения автоматически
запускаются пять постоянных тестов, а отчёт сохраняется в
`checkpoints/rut5-absum-finetuned-v4/test_results.json`.

Автоматическую проверку можно отключить аргументом `--skip-test-run`.

### 5. Проверка модели

Проверка основной модели:

```powershell
python evaluate_model.py
```

Проверка экспериментального чекпоинта:

```powershell
python evaluate_model.py --model-name checkpoints/rut5-absum-finetuned-v4 --output results/v4_test_results.json
```

### 6. Запуск API

```powershell
python run_api.py
```

После запуска доступны:

- `GET http://127.0.0.1:8000/health` — проверка работы сервера;
- `POST http://127.0.0.1:8000/summarize` — суммаризация текста;
- `http://127.0.0.1:8000/docs` — интерактивная документация FastAPI.

Пример тела запроса:

```json
{
  "text": "Исходный текст для суммаризации",
  "model_name": "checkpoints/rut5-absum-finetuned",
  "device": "cpu"
}
```

### 7. Тесты проекта

```powershell
python -m pytest -q
```

занимают много места и хранятся локально.

## Как работает суммаризация

1. `main.py` передаёт управление модулю `src/summar/cli.py`.
2. CLI читает исходный файл и нормализует текст.
3. `SummarizationModel` загружает токенизатор и выбранный чекпоинт.
4. Текст преобразуется в токены. Слишком длинный текст делится на части только
   при превышении допустимого числа токенов.
5. Модель RuT5 генерирует новый краткий пересказ, а не извлекает готовые
   предложения.
6. Результат очищается от повторов и незавершённых фрагментов.
7. CLI рассчитывает длину обоих текстов и фактический процент сокращения.

Целевая длина пересказа составляет примерно 30% исходного текста, то есть
сокращение — около 70%. Точное значение может отличаться, поскольку модель
завершает мысль целым предложением.

## Как работает обучение

Датасет содержит `206` пар: `163` для обучения и `43` для validation. Формат
одной записи:

```json
{
  "text": "Полный исходный текст",
  "summary": "Короткий нейтральный пересказ своими словами"
}
```

Примерное распределение жанров: 30% информационно-деловых, 32% учебных и 38%
художественных текстов. Подробные правила описаны в `data/dataset_notes.md`.

Во время обучения `src/summar/train.py`:

1. загружает и проверяет JSON-файлы;
2. токенизирует исходники и эталонные пересказы;
3. дообучает выбранный чекпоинт с разогревом learning rate и сглаживанием меток;
4. регулярно вычисляет ошибку на validation;
5. применяет раннюю остановку и восстанавливает лучший чекпоинт;
6. сохраняет модель в новую папку;
7. запускает постоянный тестовый набор.

## Постоянные тесты

В `test_texts/` находятся пять текстов разных жанров: информационный, учебный,
деловой, современный художественный и классическая проза. Их нельзя переносить
в `train.json` или `validation.json`, иначе сравнение моделей станет нечестным.

Для каждого пересказа отчёт содержит:

- процент сокращения;
- совпадение слов с эталонным summary;
- долю трёхсловных фрагментов, скопированных из исходника;
- полный текст результата для ручной проверки смысла и связности.

Числовых метрик недостаточно для окончательного выбора модели. Нужно также
проверять сохранение отрицаний, причин и следствий, фактическую точность,
пунктуацию и отсутствие оборванных предложений.
